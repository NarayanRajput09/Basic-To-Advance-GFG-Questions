## 💡 How to Add New Problems

1. **Create a topic folder** (e.g., `Arrays/`, `LinkedList/`, `DynamicProgramming/`) if it doesn't already exist.
2. **Add your solution file** (e.g., `Solution.java`) with problem description comments at the top.
3. **Update the README table** with the problem link and solution link.
4. **Commit & Push**:
   ```bash
   git add .
   git commit -m "Add solution for <Problem Name>"
   git push origin main
   ```
