## 💡 How to Add New Problems

1. **Clone the repository:**
   ```bash
   git clone https://github.com/NarayanRajput09/Basic-To-Advance-GFG-Questions.git
   cd Basic-To-Advance-GFG-Questions
   ```

2. **Add your solution file:**
   - Create or open the relevant topic directory (e.g. `Arrays/`, `DynamicProgramming/`).
   - Add your solution `.java` file.

3. **Update the Index:**
   - Add the problem entry to the corresponding table in `README.md`.

4. **Commit and Push:**
   ```bash
   git add .
   git commit -m "Add: [Topic] Problem Name Solution"
   git push origin main
   ```
